# Phase 2: Validation Budget Plan (Weeks 3-4)

## Objective: Validate conversion from click → qualified lead
## Total Budget: 300-600 TON (~$1,050-$2,100)
## Daily Budget: 20-40 TON/day (~$70-$140/day)
## Duration: 14 days

---

## Budget Allocation (Refined from Phase 1 data)

| Ad Set | % Budget | Daily TON | Total TON | Notes |
|--------|----------|-----------|-----------|-------|
| Winning Ad Set (from P1) | 45% | 13.5 | 189 | Double down on winners |
| Second-best Ad Set | 25% | 7.5 | 105 | Validate second vertical |
| New Challengers | 15% | 4.5 | 63 | Test new copy/channels |
| AS-04: E-comm/Nutra | 10% | 3.0 | 42 | New vertical test |
| AS-06: Broad Awareness | 5% | 1.5 | 21 | Brand building |
| **TOTAL** | **100%** | **30 TON** | **420 TON** | |

## Actions

### Copy Optimization
- Take winning copy from Phase 1 → create 3 iterations
- Test: slightly different pain points, CTAs, social proof
- Launch A/B Tests: AB-02 (Social Proof) and AB-03 (CTA)

### Channel Refinement
- Remove channels with CTR < 0.15% from targeting
- Add 10-15 new channels discovered via TGStat
- Test channels from Tier 2 list

### Bid Optimization
- Run AB-06 (CPM Bid test) to find sweet spot
- Adjust bids per channel cluster based on performance

### Destination Test
- Launch AB-04 (Channel vs Bot)
- Set up qualification bot if not already done

## Phase 2 Exit Criteria
✅ Cost per qualified lead < $50
✅ At least 3 qualified leads generated
✅ Winning copy identified with 90%+ confidence
✅ Channel targeting refined to top 10-15 channels
✅ Bot funnel generating interactions
