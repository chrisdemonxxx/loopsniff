## 8. DAILY OPTIMIZATION PLAYBOOK

### Daily 10-Minute Check (Same time each day)

```
MORNING CHECK (5 min):
├── Open ads.telegram.org dashboard
├── Note impressions, clicks, CTR for each ad
├── Check bot for new messages → respond immediately
└── Any ads paused/rejected? Fix

EVENING CHECK (5 min):
├── Calculate cost per bot interaction
├── Compare ads: which is winning?
├── If any ad <0.15% CTR after 2 days → pause it
└── Log everything in tracking sheet
```

### Optimization Rules

| Signal | Action |
|--------|--------|
| Ad getting 0 impressions | Raise CPM bid by 0.2 TON |
| CTR < 0.15% after 3 days | Kill the ad, launch challenger |
| CTR > 0.5% | Add 50% more budget, keep running |
| One channel driving all clicks | Create ad targeting ONLY that channel |
| Bot DMs but no qualified leads | Improve bot system prompt |
| Qualified leads but no sales | Check pricing / payment flow |
| All ads failing | Try different copy angle entirely |

### CPM Bid Ladder

Start low, increase only if under-delivering:

| Day | If <500 impressions/day | If >500 impressions/day |
|-----|------------------------|-------------------------|
| 1–2 | Increase to 0.8 TON | Stay at 0.5 TON |
| 3–4 | Increase to 1.0 TON | Stay at 0.5 TON |
| 5+ | Increase to 1.5 TON | Try reducing to 0.3 TON |

## 9. KILL/SCALE DECISION FRAMEWORK

### The $100 Budget Rule: Be Ruthless

You cannot afford to let a bad ad run. Here's your kill/scale framework:

```
          AFTER 3 DAYS
              │
    ┌─────────┼─────────┐
    │         │         │
 CTR<0.15%  0.15-0.3%  CTR>0.3%
    │         │         │
   KILL     WATCH     SCALE
    │         │         │
 Replace   Give 2     Double
 with new  more days   budget
 creative   to prove
```

### Kill Criteria (Pause immediately)
- CTR < 0.15% after 3 days AND 3,000+ impressions
- Zero bot interactions after spending $10
- Ad rejected by moderation twice

### Scale Criteria (Add budget)
- CTR > 0.3% consistently
- Getting bot DMs from the ad
- Cost per bot DM < $10
- Cost per qualified lead < $20

### Don't Touch (Let it run)
- CTR between 0.15–0.30% with <5,000 impressions (not enough data)
- First 48 hours of any new ad (learning period)
